# Guía de Contribución 🤝

¡Gracias por tu interés en contribuir a la **Guía Estratégica Definitiva de Game Dev Tycoon**!

---

## 🚀 Proceso de Contribución

1. **Haz un Fork** del repositorio.
2. **Crea una Rama** para tu funcionalidad o corrección (`git checkout -b feature/nueva-sinergia`).
3. **Realiza tus Cambios** manteniendo la coherencia visual y de datos.
4. **Comprueba los Cambios** localmente abriendo `index.html` en tu navegador.
5. **Realiza un Commit** descriptivo (`git commit -m 'Añadida sinergia de Cyberpunk en RPG'`).
6. **Envía un Push** a tu rama (`git push origin feature/nueva-sinergia`).
7. **Abre un Pull Request** explicando las mejoras propuestas.

---

## 📝 Estándares de Código

- **HTML5**: Estructura limpia y semántica.
- **CSS**: Utilizar variables definidas en `:root` en `styles.css`.
- **JS**: Mantener JavaScript vanilla sin dependencias pesadas innecesarias.

¡Gracias por ayudar a mejorar esta guía para toda la comunidad!
